<Warning>
  Response helpers are deprecated. Return raw tool, resource, and prompt
  envelopes when authoring callbacks.
</Warning>

Import the server and helpers from `mcp-use`. `mcp-use/server` is the v1
compatibility entry point.

## Prefer raw returns

This complete example uses raw tool results:

```typescript
import { MCPServer } from "mcp-use";
import { z } from "zod";

const server = new MCPServer({
  name: "status-server",
  version: "1.0.0",
});

server.tool(
  {
    name: "get-status",
    outputSchema: z.object({
      status: z.string(),
      checkedAt: z.string(),
    }),
  },
  async () => {
    const data = {
      status: "ok",
      checkedAt: new Date().toISOString(),
    };
    return {
      content: [{ type: "text", text: JSON.stringify(data) }],
      structuredContent: data,
    };
  },
);

export default server;
```

## Raw equivalents

| Deprecated helper       | Raw result                                                                             |
| ----------------------- | -------------------------------------------------------------------------------------- |
| `text(s)`               | `{ content: [{ type: "text", text: s }] }`                                             |
| `object(data)`          | `{ content: [{ type: "text", text: JSON.stringify(data) }], structuredContent: data }` |
| `array(xs)`             | `{ content: [{ type: "text", text: JSON.stringify(xs) }], structuredContent: xs }`     |
| `error(message)`        | `{ isError: true, content: [{ type: "text", text: message }] }`                        |
| `image(data, mimeType)` | `{ content: [{ type: "image", data, mimeType }] }`                                     |
| `mix(...)`              | One result with the required `content` blocks                                          |
| `widget(...)`           | A tool `view` plus raw `content` and `structuredContent`                               |

The root `mcp-use` `array(xs)` helper uses the array itself as
`structuredContent`. The `mcp-use/server` compatibility helper uses a
`{ data: xs }` wrapper. Prefer a raw array so the output matches the tool's
schema directly.

## Resources and prompts

Helpers produce tool-shaped `CallToolResult` values. Resource and prompt
callbacks still accept those values as deprecated conversion inputs, but their
direct shapes are:

```typescript
// Resource
return {
  contents: [{ uri: uri.href, mimeType: "text/plain", text: "hello" }],
};

// Prompt
return {
  messages: [
    { role: "user", content: { type: "text", text: "Review this code." } },
  ],
};
```

Raw returns make resource URIs, MIME types, prompt roles, and content blocks
explicit.

## Views

Replace `widget()` with a tool definition that includes
`view: { name: "<view-directory>" }`. A view-bound tool must declare an
`outputSchema`, and every successful callback result must include matching
`structuredContent`.

Helpers remain available from the package root:

```typescript
import { text } from "mcp-use";
```

Raw envelopes are clearer when every callback already knows its protocol
result type.
