# Documentation instructions

## TypeScript documentation

- Make all TypeScript documentation changes under `docs/typescript/`.
- Add new TypeScript pages to the v2 TypeScript navigation in `docs/docs.json`.
- Update existing v2 TypeScript pages instead of their counterparts under `docs/v1/typescript/`.
- Use `/typescript/...` for internal links between v2 TypeScript documentation pages.
- Treat `docs/v1/typescript/` as legacy documentation. Do not add or update pages there unless the user explicitly requests a v1 documentation change.
