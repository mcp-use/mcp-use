# Documentation instructions

## TypeScript documentation

- Make all TypeScript documentation changes under `docs/v2/typescript/`.
- Add new TypeScript pages to the v2 TypeScript navigation in `docs/docs.json`.
- Update existing v2 TypeScript pages instead of their counterparts under `docs/typescript/`.
- Use `/v2/typescript/...` for internal links between TypeScript documentation pages.
- Treat `docs/typescript/` as legacy documentation. Do not add or update pages there unless the user explicitly requests a v1 documentation change.
