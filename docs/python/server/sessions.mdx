In implementations using the 2025-11-25 MCP protocol, session IDs can associate requests with per-client state such as caches and rate limits. The SDK behavior described below uses the `Mcp-Session-Id` HTTP header.

**Protocol version:** MCP 2026-07-28 removed protocol-level session management and the `Mcp-Session-Id` header. The examples on this page describe the older session-based behavior, not a requirement for clients or servers implementing the newer revision. See the [2025-11-25 session management specification](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports#session-management) and the [2026-07-28 transport specification](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports).

## Legacy session flow (2025-11-25)

- SDK generates a UUID when no session header is present.
- Server returns it in `mcp-session-id` on initialize.
- Client sends the header on all requests.
- Server reuses the session; middleware sees it as `context.session_id`.

## Get session ID

```python
# Middleware
sid = context.session_id or "anonymous"

# Tool
@server.tool()
def session_id() -> dict:
    sid = server._get_session_id_from_request()
    return {"session_id": sid, "short": sid[:8] if sid else None}
```

## Per-session patterns (minimal)

**State / rate limit / cache key** by `context.session_id or "anonymous"`:

```python
class SessionState(Middleware):
    def __init__(self): self.counts = defaultdict(int)
    async def on_request(self, ctx, nxt):
        sid = ctx.session_id or "anonymous"
        self.counts[sid] += 1
        return await nxt(ctx)
```

Per-session cache:
```python
class SessionCache(Middleware):
    def __init__(self): self.c = defaultdict(dict)
    async def on_read_resource(self, ctx, nxt):
        sid = ctx.session_id or "anonymous"
        uri = str(ctx.message.uri)
        cache = self.c[sid]
        if uri in cache: return cache[uri]
        res = await nxt(ctx); cache[uri] = res; return res
```

## Notes

- The session-header flow above applies to the legacy Streamable HTTP revision, not stdio or MCP 2026-07-28.
- Use per-session storage to avoid data leakage.
- Keep session data lean; expire if needed.
