---
title: Cloudflare Workers
description: Serve mcp-use Views through a Cloudflare Workers static binding.
---

Workers are an edge runtime, so serve generated View files through the
Workers static-assets binding. Route `/assets/_mcp-use/*` to that binding and all
other requests to `server.fetch`.

```bash
MCP_URL=https://<worker>.<account>.workers.dev \
MCP_ASSETS_URL=https://<worker>.<account>.workers.dev/assets \
npm run deploy
```

Configure the asset directory as `.mcp-use/build`. The route adapter removes
the `/assets/_mcp-use/` prefix before requesting the binding, which maps it to
the generated `views/` directory.

```bash
npx --yes mcp-use@beta screenshot \
  --mcp https://<worker>.<account>.workers.dev/mcp --tool show-app \
  --output cloudflare-live-view.png
```
