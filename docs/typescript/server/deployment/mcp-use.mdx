Manufact Cloud hosts MCP servers and provides deployment logs, environments,
domains, alerting, and publishing checks. Its Cloud commands work with any MCP
framework. For the full command surface, see the [CLI reference](/typescript/api-reference/cli-reference).

## Sign in

```bash
npx mcp-use login
npx mcp-use whoami --json
```

In a terminal, login opens a verification URL and waits. An agent can run
`npx mcp-use login --json`, present the returned URL and code, then run the
returned `login --device-code` command after approval. CI can provide
`MANUFACT_TOKEN` through a secret store.

## Deploy from GitHub

Push the branch and give the Manufact GitHub App access to the repository.
Inspect access or get an installation URL with:

```bash
npx mcp-use github installations --json
npx mcp-use github repos --json
npx mcp-use github connect --json
```

Run from the project directory:

```bash
npx mcp-use deploy --name weather
```

The command creates a Cloud server or reuses the linked one, waits for deployment,
and returns its MCP URL, deployment ID, and dashboard URL. `--branch` selects the
deployment branch. `--root-dir` selects an app within a monorepo. Configure
`--build-command`, `--start-command`, `--dockerfile`, and `--region` when needed.

The project link lives in `.manufact/project.json`. Later deploys reuse it;
`--new` creates another server. To link an existing server explicitly:

```bash
npx mcp-use link --server weather --org my-team --json
```

## Deploy local source

```bash
npx mcp-use deploy . --no-github --name weather
```

Cloud builds and runs the uploaded source. A prebuilt `.mcp-use/` directory is
not required. Use build and start commands appropriate to your framework.

## Register an existing MCP endpoint

```bash
npx mcp-use deploy --external-url https://example.com/mcp --name weather
```

This connects an already-hosted server without uploading or building an app.

## Environment variables

```bash
npx mcp-use env set LOG_LEVEL=info --environment production --json
npx mcp-use env push .env.production --environment production --json
npx mcp-use env list --json
```

Listing returns keys and metadata; values are write-only. For a secret, use
`env set --sensitive` with stdin as documented by `env set --help`.

Deploy also accepts repeatable `--env KEY=VALUE` and `--env-file` options. It
writes production values when the deployment branch matches the saved production
branch; other branches receive a branch-specific preview override.

## Progress and logs

Deploy waits by default. Use `--no-wait` to return the deployment ID immediately,
then inspect progress:

```bash
npx mcp-use deployments get DEPLOYMENT_ID --json
npx mcp-use logs DEPLOYMENT_ID --build --json
npx mcp-use logs DEPLOYMENT_ID --follow
```

For publishing checks, run `npx mcp-use checklist run --json`. For an agent
working on Cloud configuration, install the version-matched skill with
`npx mcp-use skills install`.
