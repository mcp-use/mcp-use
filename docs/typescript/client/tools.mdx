Use a ready `MCPConnection` to list and call tools.

```typescript
import { MCPClient } from "@mcp-use/client";

const client = new MCPClient({
  mcpServers: { demo: { url: "http://localhost:3000/mcp" } },
});

try {
  const conn = await client.connect("demo");

  const tools = await conn.listTools();
  for (const tool of tools) {
    console.log(tool.name, tool.description);
  }

  const result = await conn.callTool("read_file", { path: "/tmp/a.txt" });

  if (result.isError) {
    console.error(result.content);
  } else {
    for (const block of result.content) {
      if (block.type === "text") console.log(block.text);
    }
  }
} finally {
  await client.close();
}
```

## Tool discovery and caching

`conn.tools` reads the cached definitions without sending a request. Call
`await conn.listTools()` to fetch fresh definitions and update that cache,
including when the server returns an empty list. If discoveries overlap, an
older request cannot overwrite a newer discovery or a tool-list notification.
Results from a connection that has since disconnected cannot update the cache
of its replacement. Each call still returns the definitions from its own
response.

The client also refreshes tools automatically when the server sends a
[`notifications/tools/list_changed` notification](/typescript/client/notifications).

For modern MCP connections in a browser, `callTool()` uses the cached schema to
generate `Mcp-Param-*` headers from `x-mcp-header` annotations and validate the
tool's output. If the server rejects those headers with `ProtocolError(-32020)`
before executing the tool, the client refreshes discovery and retries once with
headers rebuilt from the new schema. Discovery forwards the caller's `headers`,
`signal`, `timeout`, and `maxTotalTimeout` options. Generated `Mcp-Param-*` headers
on the tool call take precedence over caller-supplied headers with the same name.
Other errors, failed discovery, and a second header mismatch propagate to the
caller; changing the connection also stops recovery.

## Timeouts

Pass MCP request options as the third argument:

```typescript
const abortController = new AbortController();

await conn.callTool(
  "long_task",
  { input: "data" },
  {
    timeout: 300_000,
    resetTimeoutOnProgress: true,
    maxTotalTimeout: 900_000,
    signal: abortController.signal,
  },
);
```

## Lazy connect

```typescript
let conn = client.getSession("demo");
if (!conn) conn = await client.connect("demo");
await conn.callTool("echo", { message: "hello" });
```

`getSession` returns `null` when not connected. `requireSession` throws.
