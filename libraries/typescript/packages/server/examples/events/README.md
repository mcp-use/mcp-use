# This example moved

`examples/events` was split in two:

- [`examples/observers`](../observers): read-only operation observers
  (`server.on("mcp:tools/list:complete", …)`), the former content of this
  directory.
- [`examples/mcp-events`](../mcp-events): MCP Events with `server.event()`,
  `emit()`, and webhook, poll and push delivery with replay.

This file is a permanent redirect. The directory holds no code.
