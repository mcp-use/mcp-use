# Build ChatGPT Apps with mcp-use

mcp-use is a full-stack TypeScript framework for building MCP servers, MCP Apps, ChatGPT plugins, and cloud connectors.

It includes a Vite-based system with hot module reloading and an opinionated
way to build MCP applications. Use its native Views and MCP Apps support to
ship interactive React experiences inside ChatGPT while keeping tools useful
to the model through clear descriptions and structured results.

## Get started

Follow the guides at <https://docs.mcp-use.com/v2>.

## API reference

Consult the TSDoc bundled in the installed package and the TypeScript source
comments on disk. Inspect the project's installed `mcp-use` version, generated
types, and existing ChatGPT-specific integrations before choosing APIs or
patterns.
